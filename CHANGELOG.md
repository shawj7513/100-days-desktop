# Changelog

## 0.1.0

First release.

- 100-day poster with per-day sessions and completion
- Timed sessions with pause, resume, stop and discard; minimum session length
- Add a past session by hand
- Stats: percent complete, hours, streaks, pace, projected finish, hardest day
- Settings: course name, start date, minimum session length, seven themes
- Export to CSV, backup, and erase-everything
- Built-in Help page
- Made for the Udemy class "100 Days of Code: The Complete Python Pro Bootcamp"; unofficial and not affiliated with the course or its trademark owner
